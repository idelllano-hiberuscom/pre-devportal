Paso a paso

La integración API REST sigue los siguientes pasos, explicados en el diagrama superior.

Step 1 icon

El cliente inicia el proceso de pago desde la plataforma del comercio.

Step 2 icon

El comercio envía los datos del pago (con tarjeta) directamente a Cecabank.

Step 3 icon

Cecabank contacta con la marca sin exponer los datos del comprador.

Step 4 icon

Se muestra el resultado del pago al comprador.
