Ayuda

Preguntas Frecuentes

¿Tienes un negocio y estás interesado en realizar ventas online?
Para poder contratar el TPV Virtual debes de escribirnos a XXX o llamar a XXX para que podamos darte toda la información necesaria. Podrás comenzar a realizar ventas online en unos pocos clics.
¿Qué métodos de pago están habilitados en el TPV Virtual?
El TPV Virtual tiene disponibles múltiples métodos de pago para realizar venta online. Entre ellos se encuentran tarjetas de débito y crédito de Mastercard, Visa y American Express; Bizum, Apple Pay y Google Pay, y PlazoX.
¿Qué plataformas de comercio electrónico están integradas con nuestro TPV Virtual?
Podrás integrar nuestro TPV Virtual si tu plataforma de comercio electrónico se encuentra desarrollado con WooCommerce, PrestaShop, Magento, OsCommerce, GiveWP.
¿El TPV Virtual acepta pagos con BIZUM?
Sí, en el caso de querer activar Bizum en su comercio electrónico, debe de realizar la petición a la entidad bancaria para que le active dicho método de pago y pueda comenzar a realizar cobros vía Bizum.

Funcionalidad y contratación del TPV-Virtual

¿Cómo puedo contratar un TPV-Virtual?
Debes contactar directamente con tu entidad bancaria. Ellos te proporcionarán las condiciones del servicio, el alta del comercio, y las credenciales necesarias para comenzar con la integración.
¿Hay algún coste de alta, mantenimiento o comisión por transacción?
Sí, las condiciones comerciales dependen de tu entidad bancaria. Consulta directamente con ellos.
¿Qué entidad puedo elegir para contratar el TPV-Virtual?
Puedes contratarlo con cualquiera de las entidades financieras que ofrecen este servicio. Consulta el siguiente listado.
¿Se pueden aceptar pagos desde el extranjero?
Sí, siempre que la tarjeta del cliente esté habilitada para pagos internacionales y el país no esté restringido por normativa.
¿Se pueden aceptar otras divisas además del euro?
Por defecto, el TPV opera en euros. Para otras divisas, es necesario consultar con la entidad financiera correspondiente.
¿El TPV-Virtual está disponible en varios idiomas?
Actualmente, la interfaz del TPV está disponible en varios idiomas principales. Algunas funcionalidades específicas, como Pago Fácil, podrían estar disponibles solo en español (consulta actualizada en el manual).

Integración técnica

¿Dónde puedo conseguir el manual de integración?
El manual técnico está disponible en formato PDF. Una vez contratado el TPV puedes descargarlo desde la consola de administración o solicitarlo a tu entidad o al equipo técnico de soporte.
¿Qué opciones de integración están disponibles?
Puedes integrar mediante plugin (WooCommerce, PrestaShop, OsCommerce, Magento, GiveWP), redirección estándar, REST API para control total o iframe para pago embebido
¿El TPV cuenta con entorno de pruebas o sandbox?
Sí, por defecto al contratar un TPV-Virtual se dispone de un entorno de pruebas para realizar integraciones sin riesgo.
¿Puedo integrar el pago sin redireccionar al cliente?
Sí, usando la integración por iframe (disponible solo para tarjetas) o la REST API puedes controlar todo desde tu página.
¿Qué requisitos técnicos debe tener mi sitio web para integrar el TPV?
Tener un servidor HTTPS (con certificado SSL) y soporte para peticiones HTTP/HTTPS y JSON.

Servicios adicionales

¿Cómo se gestionan las devoluciones?
Pueden realizarse desde la consola de administración o mediante llamadas API desde el servidor del comercio.
¿Es posible realizar pre-autorizaciones?
Sí, puedes bloquear un importe y confirmarlo más tarde, ideal para reservas o validación de fondos.
¿Puedo usar el TPV para suscripciones o pagos recurrentes?
Sí, mediante el uso de tokenización de tarjetas y programación de cobros recurrentes desde tu sistema.
¿Puedo consultar el estado de una operación desde la web?
Sí, tanto desde la consola de administración como a través de servicios de consulta vía API.
¿Qué ocurre si el cliente cancela el pago?
La operación no se finaliza y el sistema lo notifica como cancelado (ERR-1054). Puedes redirigir al cliente a una página de error o volver a intentarlo.

Seguridad y normativa

¿El TPV cumple con la normativa PSD2?
Sí, el TPV-Virtual cumple con los requisitos de seguridad exigidos por la normativa PSD2, incluyendo la autenticación reforzada del cliente (SCA).
¿Se pueden realizar pagos tokenizados?
Sí, se pueden almacenar datos de tarjetas de forma segura mediante tokenización y usarlos en pagos posteriores.
¿Cumple con PCI-DSS?
Sí, la plataforma de pago cumple con los estándares PCI-DSS para el tratamiento de datos de tarjetas.
¿A quién contacto si tengo dudas técnicas o problemas en producción?
Puedes escribir al soporte técnico mediante la opción de “Contacta con un experto” disponible en la consola de administración o vía correo directo.
