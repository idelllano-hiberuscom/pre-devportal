SDK

El SDK del TPV-Virtual de Cecabank permite a los comercios integrar fácilmente pagos seguros desde sus aplicaciones móviles, tanto para plataformas iOS como Android. Cecabank proporciona librerías específicas para cada sistema operativo, facilitando así un proceso de integración rápido, seguro y eficiente.

Integración para tu APP

Librerías preconstruidas listas para integrarse en proyectos iOS y Android.

Seguridad reforzada

Autenticación integrada con 3D Secure y soporte completo para PSD2.

Escaneo de tarjeta

Captura automática de los datos mediante cámara o NFC para agilizar el proceso y evitar errores en el proceso de pago.

Prevención de fraude

Nuestras herramientas avanzadas de análisis y nuestros equipos de expertos en fraude monitorean las transacciones y ofrecen soporte siempre que lo necesites.

¿Cómo funciona nuestra integración SDK a nivel técnico?

Paso a paso

La integración SDK sigue los siguientes pasos, explicados en el diagrama superior.

El cliente inicia el proceso de pago desde la aplicación móvil del comercio. 1
La app lanza el flujo de pago a través del SDK proporcionado por Cecabank. 2
El SDK recoge los datos de pago del cliente y los envía de forma segura a Cecabank. 3
Cecabank devuelve el resultado de la operación al SDK. 4
El SDK procesa el resultado y lo comunica a la aplicación. 5
La app muestra al cliente el resultado final del pago. 6

Entornos y endpoints

Disponemos de dos entornos independientes

Sandbox

Creado para que puedas probar nuestra solución en un entorno seguro e igual que el de Producción.

Te permitirá comprobar que tu integración se ha realizado correctamente, probando todas las funcionalidades que tenemos disponibles: tipos de autenticación (frictionless, challenge) y resultados (autorizada, denegada).

Te ofrecemos un listado de tarjetas y cuentas para realizar pruebas.

Producción

Procesa pagos reales con la misma latencia que Sandbox.

Alta disponibilidad y monitorización 24x7.

Acceso a un conjunto configurable de tarjetas y cuentas para validar escenarios reales en producción.

Paso a paso de la Integración SDK iOS

A continuación, se explican los pasos para la integración SDK IOS

Paso 1

Preparar el entorno

Requisitos

  • iOS versión 11 o superior
  • Xcode 10.2 o superior

Librerías proporcionadas

  • tpvSDK.xcframework: Control de la interfaz de usuario
  • tpvLIB.xcframework: Gestión de comunicaciones y procesamiento
  • SDK3DS.xcframework: Proceso nativo de autenticación 3DS

Paso 2

Proceso de integración

Pasos

  1. Importar Librerías: Incluir archivos proporcionados en el proyecto de Xcode.
  2. Configuración Inicial: Definir parámetros clave (MerchantId, AcquiredBin, TerminalID, importe, moneda, firma).
  3. Personalización UI: Utilizar UiConfiguration para adaptar colores, fuentes e imágenes.
  4. Inicialización: Iniciar mediante métodos específicos con o sin interfaz gráfica según necesidad (start o initAuthentication).

Métodos Principales

  • initDidSuccess: Indica una inicialización correcta.
  • didStartProcessing: Notifica el comienzo de procesamiento.
  • transactionDidSuccess: Notifica la operación completada con éxito.
  • didFailWithError: Indica errores durante el proceso.

Tests de Integración

Campos definidos para accesibilidad:

  • Número tarjeta: __paymentScreen_numberTextField
  • Mes: __paymentScreen_monthTextField
  • Año: __paymentScreen_yearTextField
  • CVC: __paymentScreen_cvcTextField
