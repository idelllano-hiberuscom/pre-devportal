Hosted Checkout

El modelo de Hosted Checkout permite al comercio delegar por completo el proceso de captura de datos sensibles de tarjeta a la plataforma de pago de Cecabank, mediante una redirección segura a su TPV Virtual. Por defecto, independientemente del tipo de integración (plugin o APIs), es el tpv-virtual el responsable de solicitar datos de la tarjeta, salvo que el comercio sea PCI. Esta opción es la más utilizada por los comercios, ya que evita el tratamiento directo de datos de tarjeta y reduce significativamente los requisitos de cumplimiento normativo (PCI DSS) 

 

 

Funcionamiento general

  1. El cliente final selecciona los productos y pulsa "pagar" en la tienda online del comercio.
  2. La tienda genera un formulario HTML con todos los campos necesarios y lo envía al TPV de Cecabank.
  3. El TPV Virtual presenta una página de pago propia para que el cliente introduzca los datos de su tarjeta de forma segura.
  4. Finalizado el pago, el TPV redirige al cliente a las URLs configuradas por el comercio (URL_OK o URL_NOK), según el resultado de la operación. 

Importante: Por defecto, el TPV solicita los datos de tarjeta, ya que los comercios no están autorizados a capturarlos directamente salvo indicación expresa y autorización previa.

 

URLs oficiales del TPV Virtual

Estas URLs deben colocarse en el atributo action del formulario HTML que lanza la operación.

  • Pruebas (sandbox)  https://tpv.ceca.es/tpvweb/tpv/compra.action
  • Producción  https://pgw.ceca.es/tpvweb/tpv/compra.action

 

Campos obligatorios

Los campos esenciales que deben incluirse en el formulario son

Campos obligatorios

MerchantID []

ID del comercio.

AcquirerBIN []

Código BIN de la entidad adquirente.

TerminalID []

ID del terminal asignado.

Num_operacion []

Referencia única de operación.

Importe []

Importe en céntimos (100 = 1€).

TipoMoneda []

Código ISO de moneda (978 = EUR).

Exponente []

Valor constante (2)

URL_OK []

URL a redirigir si el pago es correcto

URL_NOK []

URL a redirigir si el pago falla

Firma []

Firma de seguridad generada por el comercio

Cifrado []

Algoritmo de firma, normalmente "SHA2"

 

Seguridad y cumplimiento 

El Hosted Checkout garantiza: 

  • Cifrado HTTPS TLS 1.2 o superior en toda la comunicación.
  • Captura segura de los datos de tarjeta directamente por Cecabank.
  • Firmado digital de todas las operaciones mediante algoritmo SHA-2.
  • Compatibilidad con 3D Secure 2.0 (Verified by Visa / Mastercard SecureCode). 

 

Consideraciones importantes 

  • No usar la URL_OK para marcar pagos como confirmados en el backend del comercio. Esta URL solo se ejecuta si el cliente pulsa "Aceptar" en la pantalla final. Para confirmación fiable, usar webhooks (comunicación online).
  • El campo número de operación no debe repetirse en un plazo inferior a 24 horas.
  • La firma debe ser calculada con los datos correctos y clave asignada por la entidad bancaria. 

 

Ventajas del Hosted Checkout 

  • Rápida integración
  • Reducción de carga normativa (PCI DSS)
  • Mayor confianza del cliente
  • Seguridad bancaria garantizada por Cecabank
