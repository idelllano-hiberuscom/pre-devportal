Anulación de operaciones

Esta API permite que los Servidores del Comercio soliciten anulaciones o devoluciones directamente desde sus propios servidores, sin necesidad de usar la Consola de Administración del Comercio, mediante una petición POST generada por el Comercio.

Conceptos básicos

Anulación

Es el proceso mediante el cual se cancela por completo una operación previamente realizada. Al anularse, la operación original y la anulación quedan enlazadas, siendo el resultado equivalente a no haber realizado nunca la operación inicial.

Importante: Este tipo de operación solo es válida durante 7 días. Si se necesita hacer una anulación pasado este plazo, se deberá de llamar a la operación de devolución por el importe total de la transacción.

Devolución

Es un reembolso parcial o total sobre una operación previamente realizada. A diferencia de la anulación, tanto la operación original como la devolución permanecen registradas como operaciones independientes.

 

Campos del formulario

A continuación, se muestran los campos obligatorios para anulaciones y devoluciones.

Campos requeridos

MerchantID []

Identifica al comercio, proporcionado al darse de alta (longitud máxima: 9).

AcquirerBIN []

Identificador de la entidad, proporcionado al darse de alta (longitud máxima: 10).

TerminalID []

Identificador del terminal. Para todos los TPV virtuales actualmente es siempre 00000003 (longitud máxima: 8).

Num_operacion []

Identificador único de la operación (puede incluir nº pedido, factura, etc.). No permite caracteres especiales como ¿, ?, %, &, *, etc (longitud máxima: 50).

Importe []

Importe en céntimos de euro, como número entero (últimos dos dígitos representan céntimos)(longitud máxima: 10).

TipoMoneda []

Código ISO-4217 de la moneda. Actualmente solo 978 (euros)(longitud máxima: 3).

Exponente [Tipo]

Siempre será 2 (longitud máxima: 1).

Referencia [Tipo]

Valor único devuelto por la Pasarela SET/SEP, imprescindible para reclamaciones o anulaciones (longitud máxima: 30).

Firma [Tipo]

Cadena generada por el comercio según el procedimiento descrito en "Cálculo de la firma" (longitud máxima: 256).

Cifrado [Tipo]

Siempre SHA2 (longitud máxima: 4).

Idioma [Tipo]

Código numérico del idioma para soporte multi-idioma (longitud     máxima: 4).

Descripción [Tipo]

Texto descriptivo de la operación para consultas futuras (longitud    máxima: 255).

URLs para Formularios

Estas URLs deben colocarse en el atributo action del formulario HTML que lanza la operación.

Los formularios deben dirigirse a las siguientes URLs según el entorno y tipo de operación

Anulaciones Totales

  • Desarrollo https://tpv.ceca.es/tpvweb/anulaciones/anular.action
  • Producción https://pgw.ceca.es/tpvweb/anulaciones/anular.action

Anulaciones Parciales (Devoluciones)

  • Desarrollo https://tpv.ceca.es/tpvweb/anulaciones/anularParcial.action
  • Producción https://pgw.ceca.es/tpvweb/anulaciones/anularParcial.action

 

Nota Asegúrese de reemplazar los valores marcados con ## por los valores reales al implementar el formulario. Al copiar este código, verifique que las comillas dobles (") no sean sustituidas por comillas simples ('').

Notificaciones HTTP/HTTPS

La función principal de este proceso es que el comercio pueda actualizar automáticamente sus bases de datos internas con esta información.

Para ello, el comercio debe proporcionar una URL específica donde se recibirán los siguientes parámetros.

Anulación Parcial desde la WEB del Comercio

Para utilizar esta opción, el comercio debe contar con autorización previa de la entidad. 

Una vez habilitada esta opción, desde la Consola de Administración se podrá realizar tanto anulaciones totales como parciales. Consulte la documentación específica del apartado correspondiente. Por defecto esta opción está activada para todos los comercios. No requiere solicitud por parte del comercio. 

URLs para Anulación Parcial (WEB del comercio):

Pruebas

https://democonsolatpvvirtual.ceca.es/webapp/ConsTpvVirtWeb/ConsTpvVirtS?modo=anularOperacionExt&TIPO_ANU=P&amp;...

Producción

https://comercios.ceca.es/webapp/ConsTpvVirtWeb/ConsTpvVirtS?modo=anularOperacionExt&TIPO_ANU=P&...
